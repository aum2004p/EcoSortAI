3

สถาปัตยกรรม AI

ใช้ Deep Learning 3 โมเดลทำงานร่วมกัน แต่ละโมเดลมีหน้าที่ชัดเจน

Input

📤 อัปโหลดภาพ / เฟรมจากกล้อง

รับภาพจากผู้ใช้ผ่านหน้า Scanner หรือ Live Camera

↓
M1

🎯 Model 1: YOLO Object Detection

ตรวจจับวัตถุในภาพด้วย Bounding Box จำแนกเป็น 6 ประเภทขยะ ส่งออก: ตำแหน่ง, ประเภท, ค่าความมั่นใจ

จากนั้น Crop ภาพวัตถุแต่ละชิ้นเพื่อส่งให้โมเดลถัดไป

↓
M2

🔬 Model 2: CNN Quality Classifier

รับภาพที่ Crop มา จำแนกสภาพเป็น สะอาด / ปนเปื้อน ด้วย Transfer Learning จาก ResNet18

ส่งออก: คุณภาพ (clean/contaminated) + ค่าความมั่นใจ

↓
R

💡 Recommendation Engine

ใช้ผลจาก M1 + M2 ค้นหาใน Knowledge Base แนะนำถังขยะ วิธีเตรียม และการจัดการที่เหมาะสม

↓
M3

🔮 Model 3: Time Series Predictor

วิเคราะห์ข้อมูลการสแกนสะสม ใช้ Linear Regression + Moving Average พยากรณ์ปริมาณขยะในอนาคต

ส่งออก: จำนวนขยะที่คาดการณ์, แนวโน้ม, ระดับความมั่นใจ

↓
Out

🖥️ Web Application + Dashboard

แสดงผล บันทึกข้อมูล วิเคราะห์สถิติ คำนวณ CO₂ และสร้างรายงาน

ข้อดีของการแยกโมเดล: แต่ละโมเดลทดสอบและวัดประสิทธิภาพได้อิสระ ไม่ใช่เพิ่มความซับซ้อนโดยไม่มีเหตุผล
4

Dataset ที่ใช้

Datasetใช้ฝึกโมเดลขนาด
TrashNet จำแนกประเภทขยะ (YOLO baseline) 2,527 ภาพ · 6 ประเภท
RealWaste เพิ่มความหลากหลายจากสภาพแวดล้อมจริง 4,752 ภาพ · 9 ประเภท
ภาพสิ่งปนเปื้อน (เก็บเอง) ฝึก CNN Quality Classifier เป้าหมาย 300–500 ภาพ/สถานะ

TrashNet และ RealWaste ไม่มี Label สิ่งปนเปื้อน จึงต้องรวบรวมและติด Label เพิ่มเติมสำหรับ Model 2 แยกต่างหาก
